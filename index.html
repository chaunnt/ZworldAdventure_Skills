Skill là gì?

Một thư mục, một việc

Skill là thư mục chứa SKILL.md: phần đầu mô tả làm gì, khi nào dùng; phần thân là quy trình, bảng tra nhanh và checklist.

Tải theo nhu cầu

Agent chỉ đọc mô tả ngắn của mọi skill. Khi yêu cầu khớp, nó mới mở SKILL.md, rồi mới tới tài liệu chi tiết trong references/.

Người và máy cùng đọc

Tài liệu tham chiếu viết bằng HTML5 tự chứa: mở bằng trình duyệt cho người, có cấu trúc rõ, kèm JSON cho máy. Hình vẽ luôn được mô tả bằng lời.

skills/<ten-skill>/
├── SKILL.md        # frontmatter (name, description) + hướng dẫn
├── references/     # tài liệu tra cứu chi tiết (.html, .md)
├── assets/         # mẫu, template dùng để tạo đầu ra
└── scripts/        # mã hỗ trợ (tuỳ chọn)
dist/<ten-skill>/   # bản đóng gói: .zip cho Claude, .prompt.md cho ChatGPT/Gemini

Viết skill chuẩn đa nền tảng

viet-skill v1.0.0

Tạo mới hoặc chỉnh sửa một skill trong repo ZworldAdventure_Skills theo chuẩn Agent Skills (SKILL.md + references + assets) để dùng được trên Claude (claude.ai, Claude Code, API), ChatGPT (Custom GPT, Codex), Gemini (Gem, Gemini CLI) và các agent khác. Dùng khi người dùng muốn "viết skill", "tạo skill mới", "chuyển tài liệu/PDF/quy trình thành skill", "đóng gói skill cho ChatGPT/Gemini", hoặc rà soát một skill có đúng chuẩn không.

  • assets/SKILL.template.md
  • references/nen-tang.md

Cách dùng trên từng nền tảng

Claude

  • claude.ai / Desktop: Settings → Capabilities → Skills → Upload, chọn tệp .zip.
  • Claude Code:
    /plugin marketplace add chaunnt/ZworldAdventure_Skills
    /plugin install zworld-skills@zworld-skills
  • Hoặc chép thư mục skill vào ~/.claude/skills/.

ChatGPT

  • Custom GPT / Project: upload tệp .prompt.md vào Knowledge (Project files).
  • Instructions: “Làm việc theo skill trong tệp <tên>.prompt.md ở Knowledge.”
  • Codex: chép thư mục skill vào thư mục skills của Codex.

Gemini

  • Gem: upload .prompt.md vào Knowledge, hoặc dán nội dung vào Instructions.
  • AI Studio: dán .prompt.md vào System instructions.
  • Gemini CLI: chép thư mục skill vào thư mục skills của Gemini CLI.

Agent khác

  • Clone repo — AGENTS.md ở gốc chỉ cho agent (Cursor, Copilot, Windsurf…) cách tìm và dùng skill.
  • Agent tự viết: đọc skills.json để lấy danh sách và mô tả.

Chi tiết: skills/viet-skill/references/nen-tang.md.

Viết skill mới

  1. Nhờ AI dùng skill viet-skill (“tạo skill từ tài liệu này”), hoặc chép skills/viet-skill/assets/SKILL.template.md vào skills/<ten-skill>/SKILL.md.
  2. Viết description nêu rõ làm gì và khi nào dùng; đưa chi tiết dài vào references/; mô tả mọi hình vẽ bằng lời.
  3. Chạy python3 scripts/build_skills.py để kiểm tra, đóng gói và cập nhật trang này.
  4. Commit cả skills/, dist/, skills.json, index.html.
