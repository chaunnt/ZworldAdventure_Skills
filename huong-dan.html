Hướng dẫn sử dụng và viết skill

Mỗi skill viết một lần theo chuẩn mở Agent Skills, dùng được trên nhiều nền tảng. Bản đóng gói nằm trong dist/<ten>/: .zip cho Claude, .prompt.md (một tệp gộp) cho ChatGPT, Gemini và model khác.

Cấu trúc một skill

skills/<ten-skill>/
├── SKILL.md        # frontmatter (name, description, metadata.category, metadata.summary) + hướng dẫn
├── index.html      # trang giới thiệu (sinh tự động)
├── references/     # tài liệu tra cứu chi tiết (.html, .md) — chỉ đọc khi SKILL.md chỉ dẫn
└── scripts/        # mã hỗ trợ (tuỳ chọn)

Cài đặt theo nền tảng

Claude

  • claude.ai / Desktop: Settings → Capabilities → Skills → Upload tệp .zip.
  • Claude Code: /plugin marketplace add chaunnt/ZworldAdventure_Skills rồi /plugin install zworld-skills@zworld-skills.
  • Hoặc chép thư mục skill vào ~/.claude/skills/.

ChatGPT

  • Custom GPT / Project: upload .prompt.md vào Knowledge.
  • Instructions: “Làm việc theo skill trong tệp <tên>.prompt.md ở Knowledge.”
  • Codex: chép thư mục skill vào thư mục skills của Codex.

Gemini

  • Gem: upload .prompt.md vào Knowledge hoặc dán vào Instructions.
  • AI Studio: dán .prompt.md vào System instructions.
  • Gemini CLI: chép thư mục skill vào thư mục skills của Gemini CLI.

Agent khác

  • Đọc llms.txt hoặc skills.json trước, rồi mới mở SKILL.md cần thiết.
  • Clone repo: AGENTS.md ở gốc chỉ cho Cursor, Copilot, Windsurf… cách dùng skill.

Chi tiết: skills/cach-viet-van-ban-skill-ai-da-nen-tang/references/nen-tang.md.

Viết skill mới

  1. Dùng skill cach-viet-van-ban-skill-ai-da-nen-tang hoặc chép skills/cach-viet-van-ban-skill-ai-da-nen-tang/assets/SKILL.template.md.
  2. Khai báo metadata.category (có trong categories.json) và metadata.summary ≤ 160 ký tự.
  3. Chạy python3 scripts/build_skills.py — tự sinh lại trang, llms.txt, sitemap, gói tải về.
  4. Commit toàn bộ thay đổi.
