Khi nào dùng

Đưa một bộ data (file Excel/CSV/JSON khách hàng, đối tác, tham chiếu) vào kho data private ZWorldAdventur_Data đúng thư mục, kèm README, cập nhật structure.json và catalog.json, commit và push. Dùng khi người dùng gửi file data, khi tìm được data từ nguồn ngoài, hoặc nói "lưu data này vào repo".

Thứ tự đọc cho AI

  1. 01_khach-hang/doanh-nghiep/ — Data khách hàng gốc, chia <chu-de>/<nam>/<dia-ban>_<dot>/
  2. 02_doi-tac/<ten-doi-tac>/<YYYY-MM>/ — Data đối tác, file đối soát
  3. 03_du-lieu-tam/<YYYY-MM-DD>_<mo-ta>/ — Data tạm
  4. 04_ket-qua-loc/<YYYY-MM-DD>_<mo-ta>/ — Kết quả lọc
  5. 05_tham-chieu/ — Danh mục tra cứu dùng chung
