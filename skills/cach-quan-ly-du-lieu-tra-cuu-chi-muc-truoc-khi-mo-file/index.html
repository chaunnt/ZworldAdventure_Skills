Đọc SKILL.md Tải .zip (Claude) Tải .prompt.md (ChatGPT, Gemini…)

Khi nào dùng

Tra cứu kho data ZWorldAdventur_Data bằng chỉ mục (catalog.json, structure.json) và script search.py thay vì mở từng file để dò. Dùng mỗi khi cần biết kho có data gì, file nào chứa thông tin cần tìm, hoặc tìm một MST/tên/SĐT cụ thể.

Thứ tự đọc cho AI

  1. catalog.json — Mỗi file data: duong_dan, mo_ta (lấy từ README thư mục), sheets[] gồm cot, dong_tieu_de, so_dong_du_lieu | Luôn đọc đầu tiên
  2. structure.json — Cây thư mục và purpose của từng thư mục | Khi cần biết nên tìm hoặc lưu ở đâu
  3. <thu-muc>/README.md — Nguồn, ngày nhận, lưu ý của bộ data | Khi mo_ta trong catalog chưa đủ
